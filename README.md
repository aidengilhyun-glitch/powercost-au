# PowerCost AU

A fast, mobile-friendly Australian appliance electricity cost calculator.

## Current V1

- Daily, monthly and yearly running-cost estimates
- Annual energy-use estimate
- Adjustable watts, hours, days per week and electricity tariff
- Presets for dryers, air conditioners, heaters, pool pumps, fridges, dishwashers, washing machines, dehumidifiers, EV charging, gaming PCs, coffee machines and air fryers
- Clear methodology and consumer disclaimer
- Responsive, dependency-free static site

## Revenue plan

1. Publish useful calculator pages and earn organic search traffic.
2. Apply for an advertising network only after sufficient original content and traffic.
3. Add clearly disclosed affiliate links only where they genuinely help visitors.
4. Use Search Console data to expand the appliances people are already searching for.

No revenue is guaranteed. Traffic, usefulness, trust and ongoing testing are the main variables.

## Next milestones

- Individual SEO landing pages for the highest-intent appliance searches
- State and tariff comparison content using cited sources
- Structured data, sitemap and privacy/about pages
- Hosting, analytics and Search Console
- Ad and affiliate placeholders activated only after account approval
